Botón Alerta

Acá también voy a repasar algo que ya sé, y es el botón alerta, que igual simplemente es muy fácil. Simplemente en el JavaScript ponemos lo siguiente:

alert('Hola, esto es una alerta. Aparecerá en la parte superior del navegador, y arriba de este texto dirá algo como 'tu página dice:'. Recuerden poner comillas de verdad.')

Y, acá abajo les dejo el botón bien simplón.

Por cierto, nunca les dije cómo se coloca el botón en el HTML. Simplemente colocan:

<input type='button' value='Siguiente' id='btn_sig'></input>

Obviamente explico lo básico: 'input' es la etiqueta, 'type' es el tipo, que para que lo que se 'genere' sea el botón, deberemos colocar 'button', luego, 'value' es el atributo en donde adentro colocamos el texto del botón, como por ejemplo 'Siguiente'. Luego el identificador, que se coloca el atributo 'id='boton_siguiente''. Podés considerarlo opcional porque no le cambia la funcionalidad, pero si querés llamarlo en el Style.CSS y/o el JavaScript, lo vas a necesitar sí o sí, porque para darle funcionalidad necesitás el JavaScript, y el estilo se hace con el CSS así que... Bueno, es algo que se necesita sí o sí. Para aquellos que hagan páginas y ya sean profesionales en su trabajo harán esto de manera automática, pero para los novatos(incluyéndome), recomiendo que todo objeto tenga su 'id' o 'class' para poder llamarlo en cualquier momento con CSS, o un id que debe tener un nombre antes no definido para el js. El 'class' es como el 'id' pero puede colocarse más veces y no necesariamente deberá ser único.

Otros apartados en CSS

Ahora vamos con el CSS. CSS es la abreviación de 'Cascading Style Sheet' u 'Hoja de Estilo en Cascada', en español. Si te dejas guiar por los "comandos" html que puse, probablemente la página va a salir medio simplona, como que le falta algo... Bueno, eso es el CSS.

Acá como se ve, todo está centrado, con margen en los lados, un fondo con un pequeño degradado, algunos textos con fondos de colores y bordes con radio a cada cosa xdxd... Y aquellos que no sepan probablemente se pregunten: '¿Cómo hago esto?'. Bueno, ahora toca pasarles tuto piola. Como se los explico con texto, es fácil que una IA me lo agarre y me lo resuma mejor de lo que se los enseño, pero nada que ver weon, así que, espero que a ustedes les sirva. Así que bueno, que se comience con el CSS.

body { display: flex; flex-direction: column; background-color: black; align-items: center; color: white; }

(Código CSS).

Estos dos elementos('display: flex' y 'flex-direction: column') crean juntos una organización vertical en donde el siguiente elemento se mostrará en un salto de línea o abajo del anterior con un margen superior e inferior predeterminados, pero que puedes reemplazar su valor cambiándolo en CSS. No puedo brindate la definicón exacta, pero creo que estoy bastante cerca.
